# 💗 Love World
Setup: `npm install` then `npm run dev` (open the printed localhost link).
Photos: put your pictures in `public/images/` named photo1.jpg ... photo6.jpg (or edit names in `src/data/loveConfig.js`). Missing photos show a cute placeholder.
Music: copy a song you have permission to use to `public/music/our-song.mp3`. It starts only after she clicks the welcome button.
Customize: everything (names, dates, letter, slogans, timeline, captions, final message) lives in `src/data/loveConfig.js`. Cat colors: `src/Cats.jsx`.
Deploy free: `npm run build`, then drag the `dist` folder onto app.netlify.com/drop, or push to GitHub and import the repo at vercel.com (framework: Vite, defaults work).
